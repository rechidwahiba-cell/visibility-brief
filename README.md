# Search and AI Visibility Brief

Try it: **[rechidwahiba-cell.github.io/visibility-brief](https://rechidwahiba-cell.github.io/visibility-brief/)**

A tool for marketing managers who want to prepare the search and AI visibility of a site themselves, page by page, and hand it over to an SEO expert and a tech team in one file.

## What it covers

1. **Site and pages**: what the site is and the list of its pages, whether there are two or ten
2. **Keywords**: one main keyword per page, with a warning when two pages compete
3. **Page by page**: title, meta description, address, headings, questions and answers, share tags, with counters, a search result preview and the code for each page
4. **Technical requests**: indexing, sitemap, robots.txt and AI crawlers, canonical addresses, redirects, speed, measurement, structured data, languages, each marked You, SEO or Tech
5. **AI search**: what helps a site get read and cited by AI assistants, labelled Established, Emerging or Unproven
6. **Hand over**: an Excel pack for the SEO expert, another for the tech team, and a ready message for each
7. **Check after launch**: paste the source of a published page and get a plain verdict against the spec

It also writes prompts, filled with your own details, to use in an AI assistant for keywords, titles, descriptions, outlines and answers.

## How it works

A single HTML file with no framework, no build step and no server. The Excel files are generated in the browser. The brief is saved in the browser as you type and can be saved to a file, reopened later or passed to a colleague. Nothing is sent anywhere.

The tool does not know search volumes and cannot read a live site: keyword ideas need checking in a keyword tool, and the page check works on pasted source.
